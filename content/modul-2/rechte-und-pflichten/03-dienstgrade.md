# Dienstgrade

Die Dienstgrade der Freiwilligen Feuerwehr in NRW, von unten nach oben. Bei den ersten Dienstgraden zeigen rote Streifen auf dem Schulterabzeichen den Rang.

| Nr. | Dienstgrad | Abzeichen (laut Folien) |
|---|---|---|
| 1 | Feuerwehrfrau-Anwärterin / Feuerwehrmann-Anwärter | ohne Streifen |
| 2 | Feuerwehrfrau / Feuerwehrmann | 1 Streifen |
| 3 | Oberfeuerwehrfrau / Oberfeuerwehrmann | 2 Streifen |
| 4 | Hauptfeuerwehrfrau / Hauptfeuerwehrmann | 3 Streifen |
| 5 | Unterbrandmeisterin / Unterbrandmeister | |
| 6 | Brandmeisterin / Brandmeister | |
| 7 | Oberbrandmeisterin / Oberbrandmeister | |
| 8 | Hauptbrandmeisterin / Hauptbrandmeister | |
| 9 | Brandinspektorin / Brandinspektor | |
| 10 | Brandoberinspektorin / Brandoberinspektor | |
| 11 | Stadtbrandinspektorin / Stadtbrandinspektor | |

> [!MERKE] Neue Mitglieder beginnen als **Anwärter/in**. Nach der Grundausbildung folgt **Feuerwehrmann/-frau**.
