## Knoten und Stiche

### Mit welchem Knoten verbindet man zwei Leinen UNGLEICHEN Materials?
- [ ] Kreuzknoten
- [x] Schotstek
- [ ] Mastwurf
- [ ] Palstek
> Der Kreuzknoten nur bei gleichem Material, der Schotstek auch bei ungleichem.

### Was ist die Schwäche des Schotsteks?
- [ ] Er zieht sich fest zu
- [x] Er kann slippen, wenn er falsch gebunden wird
- [ ] Er lässt sich nur mit Karabiner binden
- [ ] Er ist nur für Stahlseile geeignet
> Richtig gebunden zieht er sich nicht zu – falsch gebunden kann er sich lösen.

### Welcher Knoten gilt als „Rettungsknoten“?
- [ ] Mastwurf
- [ ] Zimmermannstich
- [x] Palstek
- [ ] Halbschlag
> Der Palstek (Pfahlstich) bildet eine Schlinge, die sich nicht zuzieht.

### Mit welchen Knoten legt man die Leine an einer Stange oder einem Pfahl fest? (mehrere richtig)
- [x] Mastwurf
- [x] Doppelter Ankerstich
- [ ] Kreuzknoten
- [ ] Spierenstich
> Mastwurf und doppelter Ankerstich – beide gelegt oder gestochen.

### Welcher Stich wird hauptsächlich beim Aufziehen von Schlauchleitungen und Äxten verwendet?
- [x] Doppelter Ankerstich
- [ ] Achterknoten
- [ ] Halbmastwurf
- [ ] Schotstek
> Er lässt sich an jeder beliebigen Stelle der Leine anbringen.

### Wofür wird der Zimmermannstich verwendet?
- [ ] Zum Verbinden zweier Leinen
- [x] Mehrzweckleine am Saugkorb befestigen, Rundhölzer/Balken hochziehen
- [ ] Als dynamische Sicherung im Karabiner
- [ ] Zum Sichern einer Person auf der Leiter
> Saugkorb, Pfähle, Stämme, Baukonstruktionen und Hochziehen von Rundhölzern.

### Welcher Knoten wird als dynamische Sicherung im Karabiner verwendet?
- [ ] Palstek
- [ ] Kreuzknoten
- [x] Halbmastwurf
- [ ] Doppelter Ankerstich
> Er kehrt sich unter Last selbst um und kippt immer auf die richtige Seite.

### Wozu dient der Halbschlag?
- [x] Andere Stiche sichern und Geräte beim Hochziehen stabilisieren
- [ ] Zwei Leinen ungleichen Materials verbinden
- [ ] Eine Person retten
- [ ] Die Schiebleiter ausziehen
> Der „halbe Schlag“ sichert und stabilisiert.

### Wozu kann der Spierenstich dienen? (mehrere richtig)
- [x] Zwei etwa gleich dicke Seile verbinden
- [x] Einen anderen Knoten sichern
- [ ] Eine Leiter am Fenster festlegen
- [ ] Als Rettungsschlinge
> Beides steht im Handout.

### Was soll man mit dem „Feuerwehrverzweiflungsknoten“ tun?
- [ ] Ihn bei Zeitnot bevorzugt verwenden
- [x] Ihn durch einen feuerwehrtechnischen Knoten ersetzen
- [ ] Ihn mit einem Halbschlag sichern
- [ ] Ihn nur bei Übungen einsetzen
> Für ihn gibt es keine Regeln – seine Festigkeit ist unberechenbar.
